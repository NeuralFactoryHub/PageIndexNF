# User Story Template

Quick-start template. Copy and fill in for each story.

---

```markdown
### US-{NNN}: {Descriptive Title}

**As a** {user role / persona}
**I want to** {action or capability}
**So that** {business value or benefit}

**Acceptance Criteria:**

- **Given** {precondition or starting context}
  **When** {user action or system event}
  **Then** {expected, observable outcome}

- **Given** {another precondition}
  **When** {another action}
  **Then** {another outcome}

**Notes:**
- {Technical considerations, open questions, or edge cases}

**Priority:** Must | Should | Could | Won't
**Size:** S | M | L | XL
**Dependencies:** {US-NNN, or "None"}
```

---

## Epic Template

```markdown
## Epic: {Epic Name}

**Goal:** {What this epic achieves}
**Personas:** {Who benefits}
**Success Metric:** {How we know it worked}

### Stories in this Epic:
- US-001: {title}
- US-002: {title}
- ...
```

## Technical Spike Template

```markdown
### SPIKE-{NNN}: {Investigation Title}

**Question:** {What do we need to find out?}
**Why:** {What's blocked until we answer this?}
**Time-box:** {Max hours/days to spend investigating}
**Output:** {Decision document, POC, or recommendation}
```
